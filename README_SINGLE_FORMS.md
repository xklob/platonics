## New single-form image collection

- [Browse all 67 single-form variants](SINGLE_FORMS.md)
- [Render code](generators/single-forms/render_single_forms.py)
- [SHA-256 file manifest](SINGLE_FORMS_MANIFEST.csv)

This collection preserves the family distinctions and one-to-one filename correspondence with the original stills. Individual subjects are framed to dominate a square black canvas. Distinct lattice compositions become individual polygon, solid, tesseract, or motif studies. Nested construction lines within one object are allowed; repeated plane tiling is removed.
